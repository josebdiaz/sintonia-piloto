# Seguridad

Este repositorio es **público** porque publica el sitio del piloto (https://sintonia.my) con GitHub Pages. Por eso aquí solo vive lo que puede ser público: código, textos y documentación del método. Los datos de participantes viven en la hoja de cálculo del piloto, no en el repositorio.

**Si encuentras una clave, un dato personal o una falla de seguridad,** no abras un issue público: escribe a jbolanos.dmi@gmail.com con el asunto «Seguridad Sintonía». Respondemos en un máximo de 3 días hábiles.

Reglas, controles y la excepción documentada: [`docs/seguridad-repo.md`](docs/seguridad-repo.md).
